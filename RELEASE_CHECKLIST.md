# Release Checklist

- [ ] Confirm that sharing the anonymized participant-level ratings is
  consistent with the ethics approval and participant consent.
- [ ] Confirm code license and data license.
- [ ] Run the empirical selected-parameter fit and regenerate all empirical
  figures.
- [ ] Regenerate all simulation figures from the saved result tables.
- [ ] Run at least one reduced smoke test for each Monte Carlo workflow.
- [ ] Confirm that the saved tables reproduce every numerical claim in the
  manuscript.
- [ ] Replace the provisional citation metadata with the accepted article
  citation when available.
- [ ] Change the GitHub repository to Public.
- [ ] Enable Zenodo integration before creating the public `v1.0.0` release.
- [ ] Add the Zenodo DOI to `README.md`, `CITATION.cff`, and the manuscript data
  availability statement.
